# Word to PDF 自動轉換工具

這是一個自動掃描桌面 `WORD` 資料夾，並將 `.docx` 檔案轉換為 `.pdf` 檔案的實用程式。

## 系統需求
- 必須安裝 **正版 Microsoft Word** 才能順利轉檔。
- 若要自行打包，需要安裝 Python 環境。

## 資料夾結構
程式執行時，會自動在 **桌面** 建立以下資料夾：
- `WORD`：請把要轉換的 `.docx` 檔案放在這裡。
- `WORD/BK`：轉換成功的 Word 檔案會被移動到這裡備份。
- `PDF`：轉換出來的 PDF 檔案會儲存在這裡。
- `PDF/BK`：程式執行時，會自動把 `PDF` 資料夾內既有的 `.pdf` 移至此處備份。

## 如何將程式碼打包成執行檔

如果你想把這個程式編譯成點擊就能執行的檔案（不需透過指令），請使用專案內建的打包安裝檔。

### 🍎 Mac 用戶
1. 雙擊執行 `build_mac.command`。
2. 腳本會自動安裝依賴套件並開始打包。
3. 等待執行完畢後，執行檔會出現在 `dist` 資料夾中，名為 `WordToPDF_Mac`。
*(註：已經預設幫腳本加上執行權限了，直接點擊即可。若權限跑掉，請在終端機輸入 `chmod +x build_mac.command`)*

### 🪟 Windows 用戶
*(請把整個資料夾複製到 Windows 電腦上再執行)*
1. 雙擊執行 `build_windows.bat`。
2. 腳本會自動安裝依賴套件並開始打包。
3. 等待執行完畢後，執行檔會出現在 `dist` 資料夾中，名為 `WordToPDF_Windows.exe`。

## 執行檔使用方式
打包完成後，你只需要把 `dist` 裡面的 `WordToPDF_Mac` 或 `WordToPDF_Windows.exe` 傳給別人。
對方只要把 `.docx` 丟進桌面的 `WORD` 資料夾，雙擊執行檔就可以全自動轉換！
